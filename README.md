Entry for the [make.fun bounty "One Word for Your Wi-Fi"](https://make.fun/bounty/u-tuan-muda-one-word-for-your-wi-fi-a1b4fd72) — one word describing my Wi-Fi, aiming to be both the funniest and the most accurate. My word is **ghosted**: the signal vanishes mid-call without explanation, then comes back acting like nothing happened.

## Run

```sh
python3 main.py
```

Writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). No network, no dependencies, deterministic.
